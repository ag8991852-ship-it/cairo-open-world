# القاهرة الكبرى — نسخة تجريبية 0.1

لعبة عالم مفتوح ثلاثية الأبعاد تعمل في المتصفح باستخدام Three.js.

## تشغيل محلي
افتح المشروع عبر خادم ملفات ثابت (مثل VS Code Live Server)؛ لا تفتح index.html مباشرة لأن المتصفح قد يمنع تحميل وحدة Three.js.

## النشر على Vercel
1. افتح https://vercel.com/new
2. استورد المستودع `ag8991852-ship-it/cairo-open-world`.
3. اترك إعدادات البناء الافتراضية لمشروع Static، واجعل Output Directory فارغًا أو `.`.
4. اضغط Deploy.

## التحكم
- الكمبيوتر: WASD أو الأسهم للحركة، Shift للجري، Space للقفز، E للتفاعل.
- الموبايل: عصا الحركة على اليسار، أزرار الجري والقفز والتفاعل على اليمين. اسحب على مساحة اللعب لتدوير الكاميرا.

## الموجود حاليًا
- مشهد مدينة ثلاثي الأبعاد مستوحى من وسط القاهرة، مع شوارع ومبانٍ ومحلات وأشجار.
- شخصية قابلة للتحريك بمنظور الشخص الثالث.
- سيارات تتحرك ومشاة يتحركون في البيئة.
- كاميرا متابعة، دورة وقت بسيطة، خريطة مصغرة، ومهمة وصول أولى بمكافأة افتراضية.
- تصميم تحكم للموبايل.

## حدود النسخة
هذه Prototype أولية بأصول هندسية مولدة برمجيًا، وليست بعدُ نسخة فوتوريالية أو مدينة القاهرة الحقيقية كاملة. لا يوجد حفظ تقدم أو ذكاء اصطناعي متقدم للشخصيات أو قيادة قابلة للتحكم في هذه النسخة. يلزم اختبارها على أجهزة فعلية وتحسين الأداء والأصول قبل اعتبارها إصدارًا عامًا.
